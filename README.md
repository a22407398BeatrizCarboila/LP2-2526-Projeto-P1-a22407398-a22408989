📘 **Enquadramento do Projeto**
---
Este projeto foi desenvolvido no âmbito da unidade curricular **Linguagens de Programação II**, da Universidade Lusófona de Humanidades e Tecnologias.

O principal objetivo do trabalho é aplicar os conceitos fundamentais da **Programação Orientada a Objetos (POO)**, nomeadamente:
- Encapsulamento  
- Herança  
- Polimorfismo  
- Abstração  

Foram introduzidos novos requisitos funcionais, como:
- Abismos 
- Ferramentas que interagem com os abismos
- Eliminação de programadores
- Gestão de turnos
- Estrutura preparada para gravação e carregamento de jogos
